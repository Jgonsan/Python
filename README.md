# Python Project

Projeto de estudos em Python, com notebooks e exemplos práticos.

## 📁 Estrutura

- `Basico.ipynb` – Conceitos iniciais de Python
- `DSZ_Cap1.ipynb` – Análises do curso Data Science
- `teste.ipynb` – Notebook de testes
- `.venv/` – Ambiente virtual (ignorado pelo Git)
- `requirements.txt` – Lista de dependências do projeto

## ⚙️ Como usar

### 1. Clone o repositório

```bash
git clone https://github.com/Jgonsan/Python
cd seu-repositorio
```

```bash
### 2. Crie e ative o ambiente virtual

python3 -m venv .venv
source .venv/bin/activate
```

```bash
### 3. Instale as dependências

pip install -r requirements.txt
```

```bash
### 4. (Opcional) Ative o kernel Jupyter

python -m ipykernel install --user --name=python-venv --display-name "Python (.venv)"
```

```bash
### 🧪 Rodar os notebooks

Você pode abrir os arquivos .ipynb usando:

VS Code com a extensão Python/Jupyter

Jupyter Lab / Jupyter Notebook
```
